NFL DFS Simulator - Lineup Optimizer

Ne yapar:
- NFL oyuncu verilerini yükler (568 oyuncu)
- 10.000 Monte Carlo simülasyonu çalıştırır
- FanDuel kurallarına uygun 9 kişilik lineup kurar
- CSV formatında çıktı üretir

Teknoloji:
- HTML/JavaScript (tek dosya, framework yok)
- Web Workers (paralel simülasyon)
- Event-driven oyun motoru

Sonuç:
- 557/557 projeksiyon eşleşti
- A+ kalite lineup üretildi
- Top 1% olasılığı: 6.3%

Not: FanDuel Türkiye'den erişilemediği için gerçek para testi yapılamadı.
